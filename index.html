    Über Mulchkarten

    Version · Offline-Karten-App für die Wegepflege mit Geo-PDFs.

    Entwickelt von dersauerlaender – per Vibe Coding zusammen mit Claude (KI von Anthropic). Code als Open Source unter der MIT-Lizenz: github.com/dersauerlaender/Mulchkarten

    Datenschutz

    • Karten, Linien, Zeiten und POIs bleiben nur auf diesem Handy. Es gibt keinen Server und kein Konto.
    • Weitergegeben wird nur, was du selbst über „Stand teilen“ verschickst.
    • Der GPS-Standort wird nur in der App verwendet und nicht gespeichert, außer in Tracks, die du selbst aufnimmst.
    • Mit Internet lädt die Übersicht Kartenbilder von OpenStreetMap (dabei wird deine IP-Adresse an deren Server übertragen). Mit ▦ abschaltbar.
    • „Navigation“, „Google Maps“ und „Teilen“ geben die Koordinaten an die gewählte App weiter.
